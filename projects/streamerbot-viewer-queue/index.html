Overview

Context

This is my favourite project that I've worked on so far. My good friends Radish and Onion were looking for a way to better keep track of viewers joining in on community game nights, and I created this tool to solve that problem for them.

What It Does

This tool creates a full queue system using Streamer.bot and plenty of custom C# code.

  • Viewers are able to join, leave, and check their position in the queue, and are also optionally able to provide their in-game names when joining.
  • Streamers and moderators are able to get the next viewer from the queue, toggle when joining is open, and reset the queue entirely.
  • There is also a configurable queue limit to prevent too many people from joining the queue, if needed.

Platform Support

Twitch Twitch Stream Together YouTube Multi-Streaming

Note: Group Mode needs to be enabled for Twitch Stream Together to function properly.

Overlay/Dock

I have also started working on a custom overlay and OBS dock so streamers can see the queue visually instead of reading chat. It shows the username (and in-game name, if provided) of everyone currently queued. An early version is on the GitHub repo linked below.
