Project

Overview

Context

This simple tool was created for my friend, Red, to track the amount of times he tells people he's going to ban them.

How It Works

I built this tool using Streamer.bot and custom C# code sub-actions. There are a few commands available to users:

  • !ban — increases the total "ban" count.
  • !ban <target> — increases the total "ban" count, and also tracks how many times that specific chatter has been "banned."
  • !bancount — displays the total ban count, and the number of bans for the user who used the command.
